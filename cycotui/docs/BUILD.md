# Building CycoTui

## Prerequisites
- .NET 9.0 SDK installed

## Building
To build the project, navigate to the `cycotui` directory and run:

```shell
cd src/CycoTui
 dotnet build
```

## Running Tests
To execute unit tests, navigate to the `cycotui` directory and run:

```shell
cd tests/CycoTui.Tests
 dotnet test
```
